What is Abot‑Kamay?

The Abot‑Kamay Health Companion Website is an offline‑first progressive web application (PWA) built specifically for BHWs and community members in rural areas. This is done by enabling systematic data collection, evidence‑based interventions, and continuous community monitoring, ultimately improving patient outcomes in underserved areas.

It functions as a health companion that provides essential tools—patient records, immunization tracking, automated immunization alerts, appointment scheduling, medicine inventory, health education, emergency contacts, offline‑local data caching, encrypted patient records, RHU service directories, emergency contacts, and cloud backup capabilities.

Optional online features (appointment requests and full‑system backup) are available when connectivity exists but are never required for core workflows.

The app aims to improve access to localize health information, enhance health worker–community communication, strengthen patient follow‑up, and increase health‑seeking behaviors despite low connectivity.
